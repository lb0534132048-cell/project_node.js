# פרויקט Node.js

שרת Express לניהול קורסים וסטודנטים. הנתונים נשמרים בקובצי JSON בתיקיית `data`
באמצעות פעולות קובץ א-סינכרוניות.

## הפעלה

1. התקיני את התלויות באמצעות `npm install`.
2. העתיקי את `.env.example` לקובץ `.env` והגדירי ערך ל-`AUTH_KEY`.
3. הפעילי את השרת באמצעות `node server.js`.

כל בקשה צריכה לכלול כותרת `auth-key` עם הערך שהוגדר ב-`.env`.
